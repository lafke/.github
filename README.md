# .github

Organization profile and default community health files for [Lafke](https://github.com/lafke).

| Path | Purpose |
| --- | --- |
| `profile/README.md` | The profile shown on the organization page. |
| `CODE_OF_CONDUCT.md` | Default code of conduct. |
| `CONTRIBUTING.md` | Default contribution guidelines. |
| `SECURITY.md` | Default security policy. |
| `SUPPORT.md` | Where to get help. |

GitHub applies the root files to every repository in the organization that does not have its
own copy.
