# AGENTS.md

Instructions for AI coding agents working in this repository. If a user's request
disagrees with this file, the user wins.

## Project

The `lafke/.github` repository: the organization profile and the default community health
files that GitHub applies to every `lafke` repository without its own copy. It holds no
code, only Markdown. This repository is public.

## Layout

- `profile/README.md`: the profile shown on https://github.com/lafke.
- `CODE_OF_CONDUCT.md`, `CONTRIBUTING.md`, `SECURITY.md`, `SUPPORT.md`: defaults.
- `README.md`: what this repository is. `AGENTS.md`: this file.

## Rules

- Everything here is public. Never mention private repositories, internal tooling, secrets
  or account details.
- Keep the profile and the defaults consistent with `lafke/lafke` (`README.md`,
  `CONTRIBUTING.md`, `SECURITY.md`). Verify a claim there before writing it here.
- The name is written `Lafke`, with a capital L and the rest lowercase, in prose. Use
  lowercase `lafke` only for code, commands, package names and URLs.
- Keep the written voice plain and direct English, with no marketing superlatives.
- Prefer short sections and tables. Keep commands copy-pasteable.
- Code, comments, commit messages, and everything published to GitHub are in English.
- Every commit message follows Conventional Commits, is all lowercase, and is 40 to 50
  characters long, counting the whole subject line (e.g. `docs: add a support page for help requests`).
  Check the length before committing.
