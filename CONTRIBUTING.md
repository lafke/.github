# Contributing

Thanks for helping improve Lafke. This page applies to every repository in the
organization that does not have its own `CONTRIBUTING.md`. The CLI has one with the
development checks:
[lafke/lafke](https://github.com/lafke/lafke/blob/main/CONTRIBUTING.md).

## Pull requests

- Keep changes small and focused: one logical change per commit.
- Use [Conventional Commits](https://www.conventionalcommits.org) (`feat`, `fix`, `docs`,
  `test`, `chore`, `ci`, `refactor`, `perf`).
- Write a subject line only, in the imperative, all lowercase, with no trailing period:
  `fix: handle an empty lockfile gracefully`. Put the reasoning in the pull request
  description.
- Run the repository's checks locally before you commit. CI runs the same ones.
- Write code, comments, commit messages and everything you publish to GitHub in English.

## AI-assisted contributions

Using AI tools is fine. You remain responsible for the result: you can explain every line you
submit, you have read the whole diff, and you ran the checks yourself. Do not put secrets,
tokens or private data into AI tools.

## Conduct

By taking part you agree to follow our [Code of Conduct](CODE_OF_CONDUCT.md).
